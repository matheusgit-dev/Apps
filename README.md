# Kingstool

**A multifunctional desktop dashboard for productivity and daily task automation.**

</div>

---

## About the Project

**Kingstool** is a utility desktop tool ecosystem built in Python. It was developed to centralize small daily automations — such as PDF handling, data formatting, and text processing — inside a modern, intuitive, and customizable dark interface.

---

## Features

-  **PDF Renamer:** Scans folders and subfolders for PDF receipts/documents, extracts beneficiary or receiver names, and automatically renames the files.
-  **CPF / CNPJ Formatter:** Bulk adds or removes standard Brazilian document formatting (`000.000.000-00` / `00.000.000/0000-00`).
-  **Text Organizer:** Groups multi-line text lists into a single organized, comma-separated sequence.
-  **Uppercase Converter:** Quickly converts text blocks to UPPERCASE.
-  **Color Customization:** Theme engine with dynamic accent color switching across the entire app interface.

---

## Built With

- **[Python](https://www.python.org/)** — Core programming language.
- **[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)** — Framework for modern Graphical User Interface (GUI).
- **[pyPDF](https://github.com/py-pdf/pypdf)** — Reading and extracting text from PDF files.
