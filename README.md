# Kingstool

**A multifunctional desktop dashboard for productivity and daily task automation.**

</div>

---

## About the Project

**Kingstool** is a utility desktop tool ecosystem built in Python. It was developed to centralize small daily automations — such as PDF handling, data formatting, and text processing — inside a modern, intuitive, and customizable dark interface.

---

## Features

-  **PDF Renamer:** Scans folders and subfolders for PDF receipts/documents, extracts beneficiary or receiver names, and automatically renames the files.
-  **CPF / CNPJ Formatter:** Bulk adds or removes standard Brazilian document formatting (`000.000.000-00` / `00.000.000/0000-00`).
-  **Text Organizer:** Groups multi-line text lists into a single organized, comma-separated sequence.
-  **Uppercase Converter:** Quickly converts text blocks to UPPERCASE.
-  **Color Customization:** Theme engine with dynamic accent color switching across the entire app interface.

---

## Sobre o Projeto

O **Kingstool** é um ecossistema de ferramentas utilitárias desktop construído em Python. Ele foi desenvolvido para centralizar pequenas automações do dia a dia — como manipulação de PDFs, formatação de dados e tratamento de texto — em uma interface moderna, intuitiva e customizável.

---

## Funcionalidades

-  **Renomeador de PDF:** Varre pastas e subpastas em busca de comprovantes/documentos PDF, extrai nomes de beneficiários, favorecidos ou pagadores e renomeia os arquivos automaticamente.
-  **Formatador de CPF / CNPJ:** Adiciona ou remove a pontuação padrão (`000.000.000-00` / `00.000.000/0000-00`) de listas de documentos em massa.
-  **Organizador de Texto:** Agrupa listas de texto quebradas em linhas em uma única sequência organizada e separada por vírgulas.
-  **Conversor Caixa Alta:** Converte rapidamente blocos de texto para letras maiúsculas.
-  **Personalização de Cores:** Sistema de temas com ajuste dinâmico da cor de destaque (*Accent Color*) em toda a interface do app.

---

## Tecnologias Utilizadas

- **[Python](https://www.python.org/)** — Linguagem base do projeto.
- **[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)** — Framework para a interface gráfica (GUI) moderna.
- **[pyPDF](https://github.com/py-pdf/pypdf)** — Leitura e extração de texto de arquivos PDF.
